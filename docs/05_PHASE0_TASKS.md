## 進め方のルール

1. **1タスク = 1コミット**。まとめてやらない
2. 各タスク完了時に **必ず push する**。ユーザーは iPhone で実物を確認して初めて判断できる
3. 数値は必ず `src/data/balance.json` に置く。**コードに直書きしない**
4. 完了条件は「実装したか」ではなく「**iPhone の画面上で確認できるか**」で書いてある。その通りに判定する
5. 迷ったら `02_CORE_SPEC.md` を正とする。仕様書にない判断をしたら、その場で仕様書に追記する

## T1. 弾幕ストレステスト ★技術選定ゲート

**目的: Web で弾幕が成立するかを、推測ではなく実測で確定させる。**

- [ ] `Pool.ts` を実装（事前確保1200、ランタイム生成ゼロ）
- [ ] `SpatialGrid.ts` を実装（64px ユニフォームグリッド）
- [ ] 敵弾600 + 自弾400 を同時に動かし、全弾に衝突判定を通すシーンを作る
- [ ] 弾は画面外に出たら回収、上限到達時は最古を強制回収
- [ ] 5分間連続で動かし、fps の推移を記録できるようにする

**完了条件**
iPhone 実機で **1000スプライト同時 + 全衝突判定** を 5分間動かし、fps を計測して報告する。

**判定ゲート**

| 結果 | 次の行動 |
|---|---|
| 安定 60fps | そのまま T2 へ。技術構成を確定 |
| 45〜60fps で揺れる | 描画・判定を最適化して再測定。改善しなければユーザーに報告して判断を仰ぐ |
| 45fps 未満 | **ここで止まる。** ユーザーに報告し、Godot への切り替えを含めて判断を仰ぐ |

> **勝手に「まあ動くから」で先に進まないこと。** ここが唯一の技術的な引き返し地点。

## T2. 入力とクラフト移動

- [ ] `Input.ts`: タッチの開始/移動/終了を正規化。マウスでも動くようにする（開発用）
- [ ] `Craft.ts`: 状態機械の骨格（MOVE / DRAIN / COUNTER）。状態名を DebugOverlay に出す
- [ ] **相対移動**で追従（指の座標＝機体座標にしない）。`followLerp = 0.5`
- [ ] 移動範囲のクランプ、DRAIN 時の慣性減衰（`driftDamping = 0.85`）
- [ ] 当たり判定のコアを小さな光点で常時表示

**完了条件**
指を動かすと機体が滑らかに追従し、**指の下に機体が隠れない**。
指を離すと状態表示が DRAIN に変わり、機体がわずかに滑って止まる。

## T3. 主砲と敵

- [ ] `BulletSystem.ts`: `Bullet` 構造体（`02_CORE_SPEC.md` §4.1 の全フィールド）
- [ ] 主砲の自動連射（`fireInterval = 0.12`、弾2発、上方向1400px/s）

**完了条件**

## T4. チャージ弾とドレイン

- [ ] 敵の射撃（`aimed` / `spread` の2パターン）
- [ ] 弾生成時に `chargeable = random() < chargeableRate`（既定 0.30）
- [ ] チャージ弾は**マゼンタ `#FF3FA4`**、通常弾は**シアン `#7FE8FF`**、両方に2pxアウトライン
- [ ] `DrainField.ts`: 扇形（半径260、上方向±55°）の吸引。0.08秒で全開
- [ ] チャージ弾のみ吸引。**通常弾は素通りして被弾する**
- [ ] 吸引された弾は**加速しながら**機体に吸い込まれ、`charge += 1`（上限30）
- [ ] 自機周囲のチャージリングが charge に比例して成長する

**完了条件**
指を離すと渦が出て、マゼンタの弾だけが加速しながら吸い込まれ、リングが太くなる。
シアンの弾は渦を無視して当たる。

## T5. カウンター ★ここが本番

**このタスクの出来がプロジェクトの成否そのもの。**

- [ ] `charge > 0` の状態でタップ → COUNTER 発動、0.35秒の無敵
- [ ] `charge >= 10` なら**画面内の敵弾を全消去**
- [ ] ダメージ = `atk * 3.0 * (1 + charge * 0.08)`
- [ ] 発動後 `charge = 0`
- [ ] **0.06秒のヒットストップ**
- [ ] 画面フラッシュ + 弾消去の波紋
- [ ] 消えた弾を**スコア粒子に変換して自機へ飛ばす**
- [ ] 吸引音のピッチを charge に応じて12段階以上で上げる
- [ ] カウンター音を charge 量で3段階以上に差し替える
- [ ] **AudioContext を「タップして開始」で unlock する**（これを忘れると無音で判定を誤る）

**完了条件**
30発溜めてカウンターを撃ったとき、**音が上がりきり、画面が止まり、弾が消し飛ぶ**。
実際に遊んで「気持ちいい」と言えること。言えないなら数値と演出を調整して繰り返す。

## Phase 0 でやらないこと（明確に禁止）

以下に手を出すと Phase 0 の目的が濁る。**やらない。**

- モジュール / チップ（ローグライト要素） → Phase 1
- パイロット複数、属性、支援機 → Phase 1〜2
- スタミナ、ガチャ、通貨、セーブ → Phase 2〜3
- 本番アート、BGM、ストーリー → Phase 0 の合否が出てから
- タイトル画面の作り込み、設定メニューの充実
